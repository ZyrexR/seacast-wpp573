## 2. JUSTIFIKASI ILMIAH SUB-AOI

Domain bujur $111,00^\circ\text{ s.d. } 113,00^\circ\text{ BT}$ dan lintang $-10,45^\circ\text{ s.d. } -8,00^\circ\text{ LS}$:
1. Merupakan **Jendela Analisis Oseanografi Beresolusi Tinggi (0,05° ~ 5,5 km)** yang berpusat di perairan selatan Jawa Timur terkait dinamika upwelling Teluk Prigi.
2. Tidak adanya data Vessel Monitoring System (VMS) atau AIS armada perahu motor lokal Prigi secara berkesinambungan di workspace berarti tidak ada bukti empiris bahwa batas kotak $111^\circ-113^\circ	ext{BT}$ adalah batas jelajah fisik eksklusif nelayan Prigi.
3. Sub-AOI ini berfungsi murni sebagai **Domain Studi Dinamika Fisik Oseanografi Skala Lokal-Mesoskala Pesisir**.
